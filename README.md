# AI Creator — Flutter Starter

نسخة أولى فعلية من تطبيق AI Creator بواجهة عربية RTL ومناسبة للبناء من الهاتف.

## الموجود حالياً
- شاشة بداية
- الصفحة الرئيسية
- توليد صورة (واجهة وتجربة إدخال)
- توليد فيديو (واجهة)
- تعديل صورة مع اختيار صورة من الهاتف
- صورة إلى فيديو مع اختيار صورة
- أعمالي
- الإعدادات
- تصميم Material 3 ودعم العربية RTL

## مهم
هذه النسخة هي أساس التطبيق وليست متصلة بمحركات توليد فعلية بعد.
توليد الصور والفيديو يحتاج محرك AI/Backend. الهدف من هذه النسخة أن تقدر تبني APK وتجرب الواجهة أولاً، ثم نضيف محرك مجاني/مفتوح المصدر في الخطوة التالية.

## البناء من الموبايل
1. فك الضغط.
2. افتح المشروع في أي بيئة Flutter أونلاين تدعم رفع مشروع ZIP، أو اربطه بمستودع GitHub ثم استخدم خدمة بناء Flutter.
3. شغّل `flutter pub get`.
4. ابنِ APK باستخدام `flutter build apk --release`.
5. نزّل APK وثبّته على هاتف Android.

## ملاحظات
- اسم الحزمة: `ai_creator`
- لا توجد مفاتيح API أو أسرار داخل المشروع.
- لا تحتاج Android Studio لتعديل الكود؛ يمكن استخدام محرر Flutter على الويب.
